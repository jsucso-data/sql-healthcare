# SQL Healthcare Claims Analysis

🚧 **Work in progress.** A full README with findings is coming soon.

SQL practice and analysis on a **synthetic** healthcare claims dataset (1,000 claims, January–June 2026). All data is fake: no real patients, providers or payers.

- `data/`: the CSV tables (`claims`, `patients`, `providers`, `procedures`)
- `scripts/generate_data.py`: the script that generates the dataset
- `exercises/`: Jupyter notebooks with SQL (DuckDB), from basics to window functions

Tools: SQL, DuckDB, Python, Jupyter.
